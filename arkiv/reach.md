# Reach

**Who this is for.** Tenants who pay a rent deposit (in the UK, a deposit of about five weeks' rent), and the landlords, agents and deposit services who need a trustworthy record when the tenant moves home.

**Where we are, honestly.** UltraRentz is a pre-revenue, solo-founder project. The hackathon build is a working testnet demo with practice money. There are no paying customers yet. In the UK, tenancy deposits must be held in a government-approved scheme, so the UK is a practice market only; a real-money pilot would need a licensed partner in another market, which is not yet confirmed.

**Evidence of interest so far.** None measured yet. The student demo has visitor tracking built in, but the counter was not deployed during the hackathon, so we have no visitor numbers to report. The problem itself is documented: see the sourced figures in the README (Generation Rent for England and Wales, Business Today for India, !WOON for the Netherlands, Threshold for Ireland).

**Does it continue after Mumbai?** Yes, as the founder's main project. The Arkiv layer is the part we expect to keep, because the verifiable-record problem exists whichever market or deposit scheme we work with. The founder has set a personal checkpoint: if there are no paying customers by around 27 April 2027, he will reconsider.
